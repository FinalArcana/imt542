# Nutrition–Cost Finder

> IMT542A Sp26 · Pete Namchaisiri

---

## About

This system combines USDA Foundation Foods nutrient data with BLS retail food price data to help users explore how nutritious different foods are relative to their cost. It is intended for students, researchers, and public health analysts interested in food affordability in the U.S. The system is accessed through a REST API or a planned web interface. Users search for a food by name, select from fuzzy-matched results, and receive a structured JSON response with nutrient and cost metrics. Data is stored locally on the server and does not require live calls to external services. Results are descriptive only and should not be used as dietary or policy guidance.

---

## Methodology

- Food nutrient data is sourced from the USDA Foundation Foods bulk dataset, stored locally as a JSON file.
- Retail price data is sourced from the BLS Average Retail Food Prices series at `https://download.bls.gov/pub/time.series/ap/`, stored locally as flat files.
- Nutrient values are expressed per 100 g. BLS prices are given per pound and converted to a per-100 g basis to allow direct comparison.
- Foods are matched between the two datasets using fuzzy name matching, since they do not share a common identifier.
- Derived metrics (protein per dollar, calories per dollar) are computed from the normalized nutrient and price values and returned alongside the raw data.
- Each response includes provenance metadata recording the source datasets and schema version.
- Local data files are updated manually when new releases are available from USDA or BLS.

---

## Access

- The system is accessed via a REST API. A web interface is also planned for users who prefer to search and browse results in a browser without making API calls directly.
- No authentication is required.
- To find a food item, call the `/search` endpoint with a plain-text food name. The API returns a ranked list of fuzzy-matched results from both datasets.
- Use the identifiers from the search results to call the `/food` endpoint and retrieve the full integrated record.


| Endpoint | Method | Description |
|---|---|---|
| `/search` | GET | Search for food items by name, returns fuzzy-matched results |
| `/food` | GET | Retrieve a full integrated record by `fdc_id` and `bls_series` |

---

## Structure

Each response from `/food` is a JSON object with the following fields:

| Field | Type | Description |
|---|---|---|
| `fdc_id` | integer | USDA Foundation Foods identifier |
| `description` | string | Food name from Foundation Foods |
| `basis_amount_g` | integer | Gram basis for all nutrient values (always 100) |
| `nutrients` | object | Nutrient values per 100 g, each with `value` and `unit` |
| `bls` | object | BLS price data including series ID, item name, normalized price, and period |
| `derivedMetrics` | object | Computed metrics: `protein_per_dollar` and `calories_per_dollar` |
| `metadata` | object | Schema version, dataset source URLs, and load timestamps |

## Example

### Search and retrieve cost metrics for chicken breast

**Step 1: Search by name**

```
GET /search?q=chicken+breast
```

```json
{
  "foundationFoods": [
    { "fdc_id": 171686, "description": "Chicken breast, raw",             "score": 98 },
    { "fdc_id": 331960, "description": "Chicken breast, cooked, roasted", "score": 91 }
  ],
  "bls": [
    { "series_id": "APU0000FF1101", "item_name": "Chicken breast, boneless, per lb.", "score": 97 }
  ]
}
```

**Step 2: Retrieve full record**

```
GET /food?fdc_id=171686&bls_series=APU0000FF1101
```

```json
{
  "fdc_id": 171686,
  "description": "Chicken breast, raw",
  "basis_amount_g": 100,
  "nutrients": {
    "protein": { "value": 21.2, "unit": "g" },
    "energy":  { "value": 120,  "unit": "kcal" },
    "fat":     { "value": 2.6,  "unit": "g" }
  },
  "bls": {
    "series_id": "APU0000FF1101",
    "item_name": "Chicken breast, boneless, per lb.",
    "price": { "value": 0.646, "unit": "USD_per_100g" },
    "period": "2024-07"
  },
  "derivedMetrics": {
    "protein_per_dollar":  { "value": 32.8,  "unit": "g_per_USD" },
    "calories_per_dollar": { "value": 185.7, "unit": "kcal_per_USD" }
  },
  "metadata": {
    "schemaVersion": "1.0.0",
    "datasetInfo": {
      "foundationFoods": { "source": "https://fdc.nal.usda.gov/" },
      "bls":             { "source": "https://download.bls.gov/pub/time.series/ap/" }
    },
    "sourceFetch": {
      "foundationFoods": { "loadedAt": "2025-05-01T00:00:00Z", "localFile": "data/foundation_foods.json" },
      "bls":             { "loadedAt": "2025-05-01T00:00:00Z", "localFile": "data/bls_retail_prices.csv" }
    }
  }
}
```

> Results are descriptive only. Do not use as dietary or policy guidance.
